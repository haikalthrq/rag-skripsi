3. HIGHLIGHTS UTAMA
============================================================

Qwen3-4B-Instruct-2507 adalah versi update dari Qwen3-4B mode non-thinking.
Model ini fokus pada penggunaan instruksi langsung, bukan reasoning eksplisit dengan blok <think>.

Peningkatan utama:
1. Kemampuan umum meningkat signifikan.
   Area yang disebutkan:
   - instruction following
   - logical reasoning
   - text comprehension
   - mathematics
   - science
   - coding
   - tool usage

2. Cakupan long-tail knowledge meningkat.
   Model punya peningkatan pengetahuan pada banyak bahasa.

3. Alignment dengan preferensi user meningkat.
   Model lebih cocok untuk tugas subjektif dan open-ended.
   Dampaknya: respons lebih membantu dan kualitas generasi teks lebih baik.

4. Long-context understanding meningkat.
   Model mendukung konteks panjang 256K.

============================================================
7. QUICKSTART HUGGING FACE TRANSFORMERS
============================================================

Kode resmi menggunakan repo ID:
Qwen/Qwen3-4B-Instruct-2507

Contoh penggunaan:

from transformers import AutoModelForCausalLM, AutoTokenizer

model_name = "Qwen/Qwen3-4B-Instruct-2507"

# Load tokenizer dan model
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype="auto",
    device_map="auto"
)

# Siapkan input
prompt = "Give me a short introduction to large language model."
messages = [
    {"role": "user", "content": prompt}
]

text = tokenizer.apply_chat_template(
    messages,
    tokenize=False,
    add_generation_prompt=True,
)

model_inputs = tokenizer([text], return_tensors="pt").to(model.device)

# Generate output
generated_ids = model.generate(
    **model_inputs,
    max_new_tokens=16384
)

output_ids = generated_ids[0][len(model_inputs.input_ids[0]):].tolist()
content = tokenizer.decode(output_ids, skip_special_tokens=True)

print("content:", content)

Penjelasan untuk AI Agent:
- tokenizer.apply_chat_template wajib dipakai agar format chat sesuai model.
- add_generation_prompt=True menambahkan sinyal agar model mulai menjawab.
- max_new_tokens=16384 adalah output length yang direkomendasikan untuk banyak query instruct.
- device_map="auto" membiarkan Transformers memilih distribusi device otomatis.
- torch_dtype="auto" mengikuti tipe yang cocok dari model, dalam konteks ini BF16 jika environment mendukung.

============================================================
8. DEPLOYMENT
============================================================

Model dapat dideploy dengan:
- sglang >= 0.4.6.post1
- vllm >= 0.8.5

Tujuan deployment:
Membuat endpoint yang kompatibel dengan OpenAI API.

Contoh SGLang:
python -m sglang.launch_server --model-path Qwen/Qwen3-4B-Instruct-2507

Catatan:
PDF menampilkan command SGLang yang terpotong karena line wrapping.
Repo ID resmi tetap Qwen/Qwen3-4B-Instruct-2507.

Contoh vLLM:
vllm serve Qwen/Qwen3-4B-Instruct-2507 --max-model-len 262144

Jika terjadi OOM:
Kurangi context length, misalnya menjadi 32768.

Contoh:
vllm serve Qwen/Qwen3-4B-Instruct-2507 --max-model-len 32768

Framework lokal yang disebut mendukung Qwen3:
- Ollama
- LMStudio
- MLX-LM
- llama.cpp
- KTransformers

Catatan praktis:
- Context 262144 sangat besar dan bisa boros VRAM/RAM.
- Untuk laptop atau GPU kecil, gunakan context lebih pendek.
- Untuk RAG skripsi, context 32768 sering lebih realistis daripada 262144.

============================================================
9. AGENTIC USE DAN TOOL CALLING
============================================================

Qwen3 disebut unggul dalam tool calling.
Qwen merekomendasikan Qwen-Agent untuk memaksimalkan kemampuan agentic.

Alasan memakai Qwen-Agent:
- Qwen-Agent sudah membungkus tool-calling template.
- Qwen-Agent sudah menyediakan parser tool-calling.
- Ini mengurangi kompleksitas implementasi manual.

Cara mendefinisikan tools:
- Pakai file konfigurasi MCP.
- Pakai tool bawaan Qwen-Agent.
- Integrasikan tool sendiri.

Contoh struktur kode dari model card:

from qwen_agent.agents import Assistant

# Define LLM
llm_cfg = {
    'model': 'Qwen3-4B-Instruct-2507',
    'model_server': 'http://localhost:8000/v1',
    'api_key': 'EMPTY',
}

# Define tools
tools = [
    {
        'mcpServers': {
            'time': {
                'command': 'uvx',
                'args': ['mcp-server-time', '--local-timezone=Asia/Shanghai']
            },
            'fetch': {
                'command': 'uvx',
                'args': ['mcp-server-fetch']
            }
        }
    },
    'code_interpreter'
]

# Define agent
bot = Assistant(llm=llm_cfg, function_list=tools)

# Streaming generation
messages = [{'role': 'user', 'content': 'https://qwenlm.github.io/blog/'}]
for responses in bot.run(messages=messages):
    pass

print(responses)

Catatan:
- PDF menampilkan beberapa baris kode yang terpotong karena layout halaman.
- Contoh di atas dirapikan agar mudah dipahami AI Agent.
- model_server menunjuk endpoint lokal OpenAI-compatible.
- api_key dapat diisi EMPTY jika endpoint lokal tidak butuh autentikasi.

10. BEST PRACTICES
============================================================

Parameter sampling yang direkomendasikan:
- Temperature: 0.7
- TopP: 0.8
- TopK: 20
- MinP: 0

Presence penalty:
- Jika framework mendukung, presence_penalty bisa diatur antara 0 sampai 2.
- Tujuannya mengurangi repetisi tanpa akhir.
- Nilai terlalu tinggi bisa menyebabkan language mixing dan sedikit penurunan performa.

Output length:
- Rekomendasi umum: 16,384 token untuk sebagian besar query instruct.

Standardisasi output untuk benchmark:
1. Masalah matematika:
   Tambahkan instruksi:
   Please reason step by step, and put your final answer within oxed{}.

2. Multiple-choice questions:
   Tambahkan instruksi agar jawaban memakai format JSON.
   Contoh:
   Please show your choice in the answer field with only the choice letter, e.g., "answer": "C".

Implikasi untuk evaluasi:
- Prompt perlu distandarkan agar output model lebih mudah dinilai.
- Untuk eksperimen skripsi, format output yang konsisten mengurangi noise evaluasi BLEU, ROUGE-L, dan evaluasi manual.

11. CATATAN UNTUK RAG PIPELINE
============================================================

Model ini bisa dipakai sebagai generator dalam pipeline RAG.

Kelebihan untuk RAG:
- Instruction following lebih kuat.
- Text comprehension meningkat.
- Long context besar.
- Non-thinking output lebih ringkas dan tidak mencampur blok reasoning internal.
- Tool usage dan agentic capability tersedia jika dibutuhkan.

Hal yang perlu dijaga:
- Jangan mengandalkan context length besar sebagai solusi tunggal.
- Tetap optimalkan chunking, retrieval, prompt, dan reranking jika ada.
- Untuk evaluasi ilmiah, catat model ID, versi model, framework, parameter decoding, context length, dan prompt template.
- Karena model ini non-thinking only, jangan berharap output berisi <think>...</think>.

Setting awal yang masuk akal untuk RAG:
- model_id: Qwen/Qwen3-4B-Instruct-2507
- max_new_tokens: sesuaikan tugas; dokumentasi memberi contoh 16384
- temperature: 0.7 untuk generasi umum
- top_p: 0.8
- top_k: 20
- min_p: 0
- context length deployment: 32768 jika resource terbatas; 262144 jika resource cukup
