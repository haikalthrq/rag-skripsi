1. Pemahaman Awal Project

User meminta saya mempelajari dokumen utama project:
- docs/SKRIPSI.md
- docs/PROJECT_CONTEXT.txt
- docs/Chat Context.txt
- seluruh repository rag-skripsi

Tujuannya agar saya memahami konteks skripsi, pipeline RAG, dataset, evaluasi, dan struktur project sebelum melakukan perubahan.

Project rag-skripsi adalah sistem Retrieval-Augmented Generation untuk tanya jawab berbasis dokumen PDF. Fokus penelitian adalah membandingkan tiga metode chunking:
- Element-Based Chunking
- Max-Min Semantic Chunking
- Recursive Chunking

Pipeline utama mencakup:
- preprocessing PDF
- chunking dokumen
- embedding chunk
- penyimpanan dan retrieval melalui vector database
- generation jawaban
- evaluasi retrieval dan generation
- visualisasi hasil evaluasi untuk Bab 6 skripsi

2. Analisis Perubahan Terakhir dan Rag Chat

User juga menanyakan format output inference dan chat pada src/streamlit/rag_chat.py. Saya menjelaskan bahwa rag_chat.py menghasilkan output chat atau batch evaluation yang mencakup:
- query
- generated answer

Beberapa iterasi format terjadi:
- awalnya satu row per baris kode
- lalu diminta satu row kode utuh
- lalu nomor baris dipindah ke kolom Baris
- lalu newline kode diperbaiki
- lalu style HTML diperbaiki agar sejajar
- lalu white-space pre dan overflow-x:auto diterapkan agar baris tidak menempel/wrap

Format akhir yang dituju:
- tabel HTML
- header judul "Algoritma n: ..."
- kolom Baris dan Kode
- kolom Baris memakai pre dengan nomor baris
- kolom Kode memakai pre/code tanpa nomor baris
- path file sumber tetap ada di baris pertama kode
- setiap tabel algoritma hanya satu row isi
- penjelasan kode berada tepat setelah algoritma
- tabel penjelasan memakai rentang baris lokal
