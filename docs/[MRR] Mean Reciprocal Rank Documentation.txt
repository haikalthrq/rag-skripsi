                      MEAN RECIPROCAL RANK (MRR)
  Sumber: rank_eval v0.1.3 — https://github.com/AmenRa/rank_eval
================================================================================

================================================================================
DEFINISI
================================================================================

Mean Reciprocal Rank (MRR) mengukur kualitas pemeringkatan dengan
mempertimbangkan posisi item relevan PERTAMA dalam daftar hasil retrieval.
Semakin tinggi posisi item relevan pertama, semakin tinggi skor MRR.

================================================================================
FORMULA
================================================================================

  MRR = (1 / |Q|) * Σ(i=1 hingga |Q|) [1 / rank_i]

Keterangan:
  - |Q|    = jumlah total query
  - rank_i = posisi (rank) item relevan pertama untuk query ke-i

================================================================================
CARA KERJA
================================================================================

Langkah-langkah perhitungan MRR:

1. Untuk setiap query, identifikasi posisi item relevan PERTAMA dalam daftar
   hasil retrieval (ranked list).

2. Hitung Reciprocal Rank (RR) untuk setiap query:
     RR = 1 / rank_i
   Contoh:
     - Item relevan pertama di posisi 1 → RR = 1/1 = 1.0000
     - Item relevan pertama di posisi 2 → RR = 1/2 = 0.5000
     - Item relevan pertama di posisi 3 → RR = 1/3 = 0.3333

3. Hitung rata-rata seluruh Reciprocal Rank (Mean Reciprocal Rank):
     MRR = mean(RR_1, RR_2, ..., RR_|Q|)

================================================================================
RENTANG NILAI DAN INTERPRETASI
================================================================================

Rentang nilai: 0 sampai 1

  - MRR = 1.0  : Item relevan selalu berada di posisi pertama untuk semua query.
  - MRR = 0.5  : Rata-rata, item relevan pertama berada di posisi ke-2.
  - MRR → 0    : Item relevan berada sangat jauh di bawah dalam hasil retrieval.

Nilai MRR yang lebih tinggi menunjukkan bahwa, secara rata-rata, item relevan
berada lebih dekat ke bagian atas daftar hasil retrieval.

================================================================================
CATATAN PENTING
================================================================================

- MRR hanya mempertimbangkan SATU item relevan pertama untuk setiap query.
  Posisi dan relevansi item relevan lainnya dalam daftar DIABAIKAN.
- MRR cocok digunakan ketika user hanya membutuhkan satu jawaban relevan
  (misalnya: question answering, navigational search).
- MRR dapat dihitung dengan atau tanpa threshold @K, contoh: mrr atau mrr@100.

CONTOH PENGGUNAAN (rank_eval)

== Persiapan Data ==

from rank_eval import Qrels, Run, evaluate

qrels = Qrels()
qrels.add_multi(
    q_ids=["q_1", "q_2"],
    doc_ids=[
        ["doc_12", "doc_25"],  # dokumen relevan untuk q_1
        ["doc_11", "doc_2"],   # dokumen relevan untuk q_2
    ],
    scores=[
        [5, 3],  # skor relevansi untuk q_1
        [6, 1],  # skor relevansi untuk q_2
    ],
)

run = Run()
run.add_multi(
    q_ids=["q_1", "q_2"],
    doc_ids=[
        ["doc_12", "doc_23", "doc_25", "doc_36", "doc_32", "doc_35"],
        ["doc_12", "doc_11", "doc_25", "doc_36", "doc_2",  "doc_35"],
    ],
    scores=[
        [0.9, 0.8, 0.7, 0.6, 0.5, 0.4],
        [0.9, 0.8, 0.7, 0.6, 0.5, 0.4],
    ],
)

== Menghitung MRR ==

# MRR keseluruhan
evaluate(qrels, run, "mrr")
>>> 0.75

# MRR bersama metrik lain
evaluate(qrels, run, ["map@5", "mrr"])
>>> {"map@5": 0.6416, "mrr": 0.75}

# Mengakses MRR per query
dict(run.scores)["mrr"]
>>> {"q_1": 1.0000, "q_2": 0.5000}

Penjelasan hasil:
  - q_1: doc_12 adalah dokumen relevan dan ada di posisi 1 → RR = 1/1 = 1.0
  - q_2: doc_11 adalah dokumen relevan dan ada di posisi 2 → RR = 1/2 = 0.5
  - MRR = (1.0 + 0.5) / 2 = 0.75

== Membandingkan Beberapa Model (MRR@100) ==

from rank_eval import compare

report = compare(
    qrels=qrels,
    runs=[run_1, run_2, run_3, run_4, run_5],
    metrics=["map@100", "mrr@100", "ndcg@10"],
    max_p=0.01  # ambang p-value untuk uji statistik
)
print(report)
