1. Ringkasan Project

- Project skripsi S1 untuk membangun dan mengevaluasi sistem RAG berbasis dokumen statistik BPS Indonesia.
- Bahasa utama: Python 3.11.x.
- Branch aktif: `main`.
- User bekerja di Windows; run definitif evaluasi generasi dilakukan di Vast AI RTX 3090 24GB.
- Tiga metode chunking yang dibandingkan:
  - `element_based`
  - `maxmin_semantic`
  - `recursive`
- Embedding utama: `Qwen3-Embedding-4B`.
- Generator utama: `Qwen3-4B-Instruct-2507`.
- Vector DB: ChromaDB lokal persisten di `data/chroma/`.

2. Ground Truth Aktif

- QA gold aktif:
  - `data/ground_truth/qa_gold_standard_rag_bps_30qa_question_newest.xlsx`
  - Sheet: `qa_gold`
  - Total: 30 QA
- Ground truth retrieval aktif:
  - `data/ground_truth/qa_pairs_binary.json`
- Skema label aktif:

5. Evaluasi dan Hasil

Evaluasi retrieval:
- Metrik: Precision@k, Recall@k, MRR
- Implementasi utama: `src/evaluation/metrics.py`

Evaluasi generasi:
- Metrik: BLEU dan ROUGE-L Recall
- BLEU memakai `sacrebleu`
- ROUGE-L memakai `rouge_score`

Hasil definitif yang dipakai:
- Folder utama:
  - `results/final/generation/`
- Format:
  - 10 file flat `eval_*_top{1..10}.csv`
- Catatan:
  - Nama file yang masih mengandung `lenient` adalah legacy naming, tetapi isi aktifnya sudah skema binary.

Angka referensi top-5 yang sering dipakai:
- Generation:
  - Element: BLEU `0.1178`, ROUGE-L `0.7005`
  - MaxMin: BLEU `0.1052`, ROUGE-L `0.6369`
  - Recursive: BLEU `0.1440`, ROUGE-L `0.6838`
- Retrieval:
  - Element: P@5 `0.129`, R@5 `0.392`, MRR `0.354`
  - MaxMin: P@5 `0.131`, R@5 `0.447`, MRR `0.349`
  - Recursive: P@5 `0.145`, R@5 `0.352`, MRR `0.429`

11. Perintah yang Sering Dipakai

- Jalankan chat demo:
  - `streamlit run src/streamlit/rag_chat.py --server.port 8501`
- Jalankan annotation app:
  - `streamlit run src/streamlit/app.py --server.port 8502`
- Jalankan test evaluasi:
  - `python -m pytest tests/test_evaluation.py -v`
- Rebuild GT binary:
  - `python scripts/convert_ground_truth_to_json.py --output data/ground_truth/qa_pairs_binary.json --relevance_threshold 1`
- Jalankan retrieval eval:
  - `python scripts/run_retrieval_eval.py --gt data/ground_truth/qa_pairs_binary.json --output results/retrieval_eval.csv --top_k 5`
- Jalankan generation eval:
  - `python scripts/run_generation_eval.py`
- Jalankan notebook visualisasi:
  - `jupyter nbconvert --to notebook --execute --inplace notebooks/eval_visualization.ipynb`
