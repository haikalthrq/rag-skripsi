                         CONTEXT PRECISION - RAGAS

================================================================================
DEFINISI
================================================================================

Context Precision adalah metrik yang mengevaluasi kemampuan retriever untuk
menempatkan chunk yang relevan lebih tinggi daripada yang tidak relevan untuk
suatu query dalam retrieved context. Secara khusus, metrik ini menilai sejauh
mana chunk yang relevan dalam retrieved context ditempatkan di posisi teratas
ranking.

================================================================================
FORMULA
================================================================================

Context Precision@K dihitung sebagai mean dari precision@k untuk setiap chunk
dalam context.

  Context Precision@K = SUM(k=1 to K) [Precision@k x v_k]
                        ----------------------------------
                        Total number of relevant items in the top K results

  Precision@k = true positives@k
                ----------------------------------------
                (true positives@k + false positives@k)

Keterangan:
  - K    = total jumlah chunk dalam retrieved_contexts
  - v_k  = indikator relevansi pada rank k, di mana v_k ∈ {0, 1}

================================================================================
CONTOH PENGGUNAAN
================================================================================

== 1. ContextPrecision (Collections-Based API) ==

Metrik ContextPrecision mengevaluasi apakah retrieved contexts berguna untuk
menjawab pertanyaan dengan membandingkan setiap context terhadap reference
answer. Gunakan ini ketika Anda memiliki reference answer yang tersedia.

Kode:
------
from openai import AsyncOpenAI
from ragas.llms import llm_factory
from ragas.metrics.collections import ContextPrecision

# Setup LLM
client = AsyncOpenAI()
llm = llm_factory("gpt-4o-mini", client=client)

# Buat metrik
scorer = ContextPrecision(llm=llm)

# Evaluasi
result = await scorer.ascore(
    user_input="Di mana Menara Eiffel berlokasi?",
    reference="Menara Eiffel berlokasi di Paris.",
    retrieved_contexts=[
        "Menara Eiffel berlokasi di Paris.",
        "Gerbang Brandenburg berlokasi di Berlin."
    ]
)
print(f"Context Precision Score: {result.value}")

Output:
  Context Precision Score: 0.9999999999

Catatan - Penggunaan Sinkron:
  Jika lebih suka kode sinkron, gunakan method .score() sebagai
  pengganti .ascore():

  result = scorer.score(
      user_input="Di mana Menara Eiffel berlokasi?",
      reference="Menara Eiffel berlokasi di Paris.",
      retrieved_contexts=[...],
  )

--------------------------------------------------------------------------------

== 2. ContextUtilization (Collections-Based API) ==

Metrik ContextUtilization mengevaluasi apakah retrieved contexts berguna
dengan membandingkan setiap context terhadap generated response. Gunakan ini
ketika Anda TIDAK memiliki reference answer, tetapi memiliki response yang
telah di-generate.

Kode:
------
from openai import AsyncOpenAI
from ragas.llms import llm_factory
from ragas.metrics.collections import ContextUtilization

# Setup LLM
client = AsyncOpenAI()
llm = llm_factory("gpt-4o-mini", client=client)

# Buat metrik
scorer = ContextUtilization(llm=llm)

# Evaluasi
result = await scorer.ascore(
    user_input="Di mana Menara Eiffel berlokasi?",
    response="Menara Eiffel berlokasi di Paris.",
    retrieved_contexts=[
        "Menara Eiffel berlokasi di Paris.",
        "Gerbang Brandenburg berlokasi di Berlin."
    ]
)
print(f"Context Utilization Score: {result.value}")

Output:
  Context Utilization Score: 0.9999999999

PENTING - Pengaruh Urutan Chunk:
  Jika chunk yang tidak relevan berada di posisi kedua → context precision TETAP SAMA.
  Jika chunk yang tidak relevan berada di posisi PERTAMA → context precision BERKURANG.

  Contoh (chunk tidak relevan di posisi pertama):
  result = await scorer.ascore(
      user_input="Di mana Menara Eiffel berlokasi?",
      response="Menara Eiffel berlokasi di Paris.",
      retrieved_contexts=[
          "Gerbang Brandenburg berlokasi di Berlin.",   # <-- tidak relevan di posisi 1
          "Menara Eiffel berlokasi di Paris."
      ]
  )
  Output: Context Utilization Score: 0.49999999995

================================================================================
LEGACY METRICS API
================================================================================

PERINGATAN DEPRECATION:
  API ini akan di-deprecated pada versi 0.4 dan dihapus pada versi 1.0.
  Harap migrasi ke collections-based API yang ditunjukkan di atas.

== Contoh dengan SingleTurnSample ==

from ragas import SingleTurnSample
from ragas.metrics import LLMContextPrecisionWithoutReference

context_precision = LLMContextPrecisionWithoutReference(llm=evaluator_llm)

sample = SingleTurnSample(
    user_input="Di mana Menara Eiffel berlokasi?",
    response="Menara Eiffel berlokasi di Paris.",
    retrieved_contexts=["Menara Eiffel berlokasi di Paris."],
)

await context_precision.single_turn_ascore(sample)

Output: 0.9999999999

--------------------------------------------------------------------------------

== Context Precision TANPA Reference ==

Metrik LLMContextPrecisionWithoutReference dapat digunakan tanpa ketersediaan
reference answer. Untuk memperkirakan apakah retrieved contexts relevan, metrik
ini menggunakan LLM untuk membandingkan setiap chunk dalam retrieved_contexts
dengan response.

Kode:
------
from ragas import SingleTurnSample
from ragas.metrics import LLMContextPrecisionWithoutReference

context_precision = LLMContextPrecisionWithoutReference(llm=evaluator_llm)

sample = SingleTurnSample(
    user_input="Di mana Menara Eiffel berlokasi?",
    response="Menara Eiffel berlokasi di Paris.",
    retrieved_contexts=["Menara Eiffel berlokasi di Paris."],
)

await context_precision.single_turn_ascore(sample)

Output: 0.9999999999

--------------------------------------------------------------------------------

== Context Precision DENGAN Reference ==

Metrik LLMContextPrecisionWithReference dapat digunakan ketika Anda memiliki
retrieved contexts DAN reference response yang terkait dengan user_input.
Untuk memperkirakan apakah retrieved contexts relevan, metrik ini menggunakan
LLM untuk membandingkan setiap chunk dalam retrieved_contexts dengan reference.

Kode:
------
from ragas import SingleTurnSample
from ragas.metrics import LLMContextPrecisionWithReference

context_precision = LLMContextPrecisionWithReference(llm=evaluator_llm)

sample = SingleTurnSample(
    user_input="Di mana Menara Eiffel berlokasi?",
    reference="Menara Eiffel berlokasi di Paris.",
    retrieved_contexts=["Menara Eiffel berlokasi di Paris."],
)

await context_precision.single_turn_ascore(sample)

Output: 0.9999999999

================================================================================
NON-LLM BASED CONTEXT PRECISION
================================================================================

Metrik ini menggunakan metode berbasis non-LLM (seperti Levenshtein distance)
untuk menentukan apakah retrieved context relevan.

== Context Precision dengan Reference Contexts ==

Metrik NonLLMContextPrecisionWithReference dirancang untuk skenario di mana
baik retrieved contexts maupun reference contexts tersedia untuk suatu
user_input. Untuk menentukan apakah retrieved context relevan, metrik ini
membandingkan setiap retrieved context atau chunk dalam retrieved_contexts
dengan setiap context dalam reference_contexts menggunakan ukuran similaritas
berbasis non-LLM.

Catatan: Metrik ini memerlukan instalasi paket rapidfuzz:
  pip install rapidfuzz

Kode:
------
from ragas import SingleTurnSample
from ragas.metrics import NonLLMContextPrecisionWithReference

context_precision = NonLLMContextPrecisionWithReference()

sample = SingleTurnSample(
    retrieved_contexts=["Menara Eiffel berlokasi di Paris."],
    reference_contexts=[
        "Paris adalah ibu kota Perancis.",
        "Menara Eiffel adalah salah satu landmark paling terkenal di Paris."
    ]
)

await context_precision.single_turn_ascore(sample)

Output: 0.9999999999

================================================================================
ID BASED CONTEXT PRECISION
================================================================================

IDBasedContextPrecision menyediakan cara yang langsung dan efisien untuk
mengukur precision dengan membandingkan ID dari retrieved contexts dengan
reference context IDs. Metrik ini sangat berguna ketika Anda memiliki sistem
ID unik untuk dokumen dan ingin mengevaluasi performa retrieval tanpa
membandingkan konten aktual.

Metrik ini menghitung precision menggunakan retrieved_context_ids dan
reference_context_ids, dengan nilai antara 0 dan 1. Nilai yang lebih tinggi
menunjukkan performa yang lebih baik. Metrik ini bekerja dengan ID bertipe
string maupun integer.

Formula:
  ID-Based Context Precision = Jumlah retrieved context IDs yang ditemukan dalam reference
                               ----------------------------------------------------------
                               Total jumlah retrieved context IDs

Kode:
------
from ragas import SingleTurnSample
from ragas.metrics import IDBasedContextPrecision

sample = SingleTurnSample(
    retrieved_context_ids=["doc_1", "doc_2", "doc_3", "doc_4"],
    reference_context_ids=["doc_1", "doc_4", "doc_5", "doc_6"]
)

id_precision = IDBasedContextPrecision()

await id_precision.single_turn_ascore(sample)

Output: 0.5

Penjelasan:
  Dari 4 retrieved context IDs, hanya 2 ("doc_1" dan "doc_4") yang ditemukan
  dalam reference context IDs, menghasilkan precision score sebesar 0.5 atau 50%.

================================================================================
RINGKASAN VARIAN METRIK
================================================================================

| Metrik                              | Kebutuhan Input                     | Metode   |
|-------------------------------------|-------------------------------------|----------|
| ContextPrecision                    | user_input + reference + contexts   | LLM      |
| ContextUtilization                  | user_input + response + contexts    | LLM      |
| LLMContextPrecisionWithoutReference | user_input + response + contexts    | LLM      |
| LLMContextPrecisionWithReference    | user_input + reference + contexts   | LLM      |
| NonLLMContextPrecisionWithReference | retrieved + reference contexts      | Non-LLM  |
| IDBasedContextPrecision             | retrieved + reference context IDs   | ID-based |
